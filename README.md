# Banking Loan Risk Assessment

## Project Overview
This project analyzes banking loan data to explore loan applications, applicant characteristics, and potential credit risk. The goal is to support data-driven lending decisions through data analysis and visualization.

## Objectives
- Analyze loan application and approval patterns.
- Explore applicant income, loan amounts, and credit history.
- Identify factors associated with potential loan risk.
- Present insights that can support responsible lending decisions.
